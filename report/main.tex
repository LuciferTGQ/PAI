\maketitle
\begin{abstract}
本文围绕工业历史轨迹上的 World Model 学习、基于模型的策略优化以及 NeoRL simulator 长期控制评价展开。报告严格区分 dynamics validation 与 simulator reward：前者用于选择 World Model，后者仅用于策略优化和最终控制评价。正文比较五类 World Model、三种 model-based planning 方法与带 behavior KL 的 MB-PPO，并在最终未使用种子上验证选定系统。
\end{abstract}
\vspace{1em}
\begin{center}
\fcolorbox{PAIBlue}{white}{\parbox{0.88\textwidth}{
\textbf{核心结果。} M100由GRU+CEM获得最佳最终控制结果；M1000与M10000由Transformer-2L+MPPI胜出。三个最终系统在seeds 100--109上相对BC的win rate均为100\%。实验同时表明，one-step prediction、recursive rollout与downstream control utility并不完全等价。
}}
\end{center}
